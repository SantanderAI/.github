# SantanderAI

Public open-source releases from Santander Group AI Lab.

We work on AI/ML research and engineering — graph neural networks for fraud
detection, anti-money-laundering benchmarks, anomaly detection, and other
financial-crime-adjacent problems.

## Governance

This organization is operated under the policies described in
[GOVERNANCE.md](https://github.com/SantanderAI/.github/blob/main/GOVERNANCE.md) —
roles, SLAs, publication gates and member-lifecycle policies.

## Contributing

Each repository documents its own contribution flow in its `CONTRIBUTING.md`.
All contributors must sign the
[Contributor License Agreement](https://github.com/SantanderAI/cla/blob/main/CLA.md).

## Security

To report a security vulnerability in any of our repositories, please follow
the disclosure process documented in that repository's `SECURITY.md`.
